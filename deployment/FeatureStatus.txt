Not operational / intentionally deferred:
- LibreChat native Code Interpreter, stateful code sessions, and programmatic code tools:
  separate sandbox deployment not approved; Hermes execution remains available
- Speech recognition and speech synthesis: optional faster-whisper / edge-tts packages
  are not in the pinned Hermes image. Speech tools are left disabled rather than
  showing a tool that fails. Needs a supported image rebuild with those extras.
- Video generation and X search: provider/account configuration still required
- Desktop computer control: needs a supported desktop runtime, absent on this server
- Advanced context-engine/A2A integrations: need a selected engine or peer configuration
- OAuth integrations, messaging channels, enterprise SSO, external tracing: need their
  own credentials and destinations; no external accounts were connected automatically
- Video analysis requires a model that supports the chosen media inputs
- Browser/mobile microphone permissions and notification permissions remain user-controlled

Operator notes:
The filesystem and knowledge-memory MCP servers are shared pilot resources, not
per-user private stores. Native LibreChat memory and RAG retain application ownership rules.
RAG embeddings and model calls use OpenRouter and are not guaranteed to execute in Canada.
Artifacts use LibreChat's default external preview infrastructure unless separately self-hosted.
The current OpenRouter credential is copied server-side into LibreChat's private .env.
If rotated in Hermes, synchronize it to LibreChat; rerunning the whole feature script also
regenerates configuration, so preserve later manual edits first.
The new services use the existing EC2 server. No additional EC2 instance was created.
Additional model, embedding, image, memory-agent, and scheduled-run usage is metered.
Private configuration backups are in /opt/librechat-hermes/backups.
Generated credentials are not included in the source folder.

Deployment:
bootstrap.sh -> enable-public-https.sh -> enable-features.sh
compose.features.yaml is included through COMPOSE_FILE in the server .env.
The scripts target Linux EC2; the D: source folder is a copy for development.

Hermes model catalog: 379 compatible text/tool models were imported from OpenRouter. LibreChat fetches Hermes /v1/models. Run sync-hermes-models.sh on EC2 to refresh the catalog after enable-features.sh. New model availability is not guaranteed by catalog membership; provider funding, model permissions, modality, and capacity still apply.
